# Online Pball Trust — standalone starter

This is a first standalone website starter for `onlinepballtrust.com`, built with plain HTML, CSS, and JavaScript. It does not require WordPress or a build step.

## Files
- `index.html` — page structure and content
- `styles.css` — responsive design
- `script.js` — mobile navigation and footer year

## Important
This is **not yet a verified, complete copy** of the current WordPress website. To reproduce its actual pages, images, and functions, we still need a WordPress export/media archive or an authorized Hostinger inspection.

Before switching the live domain:
1. Back up the current website files and database.
2. Inventory current pages, images, forms, plugins, and data-dependent features.
3. Rebuild and test any missing pages/features.
4. Deploy to staging and review before replacing the live site.
5. Never commit passwords, API keys, database dumps, or customer records.

This site clearly identifies itself as independent and does not claim official Powerball affiliation or guarantee winnings. Confirm lottery claims with the official operator.

## Preview
Open `index.html` in a browser. For Hostinger deployment, verify the target domain and preserve a backup because deployment may replace files in the web root.
